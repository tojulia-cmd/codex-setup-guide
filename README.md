## Локальный просмотр

Откройте `index.html` в браузере или запустите из этой папки:

```powershell
python -m http.server 5188 --bind 127.0.0.1
```

Перейдите на `http://127.0.0.1:5188/`. Если команда `python` недоступна, можно использовать другой статический HTTP-сервер. Для остановки нажмите Ctrl+C.

## Проверки

```powershell
node --check app.js
node tests/ui.mjs
node tests/links.mjs
```

Проверке интерфейса нужен Playwright и установленный Edge. Тест использует обычную установленную версию Playwright, а при её отсутствии ищет существующий пакет в соседнем `my-first-app/node_modules/`. Он не использует пользовательский профиль и не требует установки зависимостей для самого сайта.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch → `main` → `/ (root)` → Save. После успешного Pages deployment сайт появится по ссылке выше. Для публикации нужны права администратора репозитория. Личные аудиты и секреты сюда не добавляйте.
