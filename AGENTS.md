# Руководство Codex

Публичная инструкция на русском, опубликованная через GitHub Pages.
Читайте PROJECT.md. Правьте только этот репозиторий.
Не публикуйте личные аудиты, адреса серверов, учётные данные и данные других проектов.
Проверяйте команды по официальной документации, отмечайте дату проверки и ограничения.
После изменения интерфейса выполняйте `node --check app.js` и `node tests/ui.mjs`.
Тесты используют Playwright из соседнего проекта, если он установлен, и отдельный профиль Edge.
Перед коммитом просмотрите `git diff --staged`.
