# Руководство по настройке Codex

Самостоятельное русскоязычное руководство для Windows: Codex, GitHub, безопасная работа, SSH, OpenClaw, Telegram и распознавание голоса. Основа структуры — десять частей интенсива по ссылке в README. Текст написан заново, команды адаптированы к Codex и актуальной документации.

## Устройство

- `index.html` — полный текст, доступный без JavaScript.
- `styles.css` — адаптивный интерфейс и печать.
- `app.js` — локальный прогресс, копирование и сброс с подтверждением.
- `tests/ui.mjs` — проверки в изолированном Microsoft Edge.
- `.nojekyll` — публикация статического сайта без Jekyll.

Сервер, база данных, сборка и внешние зависимости для работы сайта не нужны. Прогресс хранится в localStorage браузера, ключ `codex-setup-guide-progress-v1`. При недоступном хранилище сайт работает в пределах открытой вкладки и сообщает об ограничении. Счётчик отражает отметки читателя, а не технический аудит.

## Публикация

GitHub Pages: ветка `main`, корень `/`. Адрес: https://tojulia-cmd.github.io/codex-setup-guide/ . Изменения публикуются после push и успешной сборки Pages.

## Границы проверки

Команды OpenClaw сверены с официальной документацией на 9 ноября 2026 года, но не выполнялись на пользовательском сервере без доступа к нему. Примеры конфигурации нужно объединять с существующими настройками. Модель, лимиты, провайдеры и элементы интерфейса могут изменяться. Полная установка окружения на чистой Windows в рамках проверки сайта не выполняется.

Видео не встроены: исходная страница называет десять видео, но не предоставляет десяти общедоступных ссылок на них. Недоступное содержимое не считается просмотренным. Личные результаты аудита не входят в этот репозиторий.
